# One Piece: Catálogo — Grand Line Wanted ☠️

Catálogo web de personagens e recompensas inspirado no universo de **One Piece**, desenvolvido com Python e Flask. O projeto permite pesquisar personagens, filtrar por tripulação e visualizar fichas individuais.

## Funcionalidades

- Catálogo responsivo de personagens
- Busca por nome ou alcunha
- Filtro por tripulação
- Página de detalhes
- Formatação de recompensas em berries
- Testes automatizados básicos

## Como executar

```bash
git clone URL_DO_SEU_REPOSITORIO
cd one-piece-catalog
python -m venv .venv
```

Ative o ambiente virtual:

```bash
# Windows
.venv\Scripts\activate

# Linux/macOS
source .venv/bin/activate
```

Instale e execute:

```bash
pip install -r requirements.txt
python app.py
```

Acesse `http://127.0.0.1:5000` no navegador.

## Testes

```bash
python -m unittest discover -s tests
```
